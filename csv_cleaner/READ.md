CSV Cleaner

A Python utility built with Pandas to clean and standardize messy CSV files.

Features
Load and inspect CSV files
Display dataset shape, columns, and information
Clean column names
Remove unnecessary spaces
Convert names to lowercase
Replace spaces with underscores
Remove leading and trailing whitespace from text values
Remove completely empty rows
Detect and remove duplicate rows
Detect missing values
Handle missing values using:
Leave unchanged
Remove rows containing missing values
Fill numeric values with mean
Fill numeric values with median
Reset DataFrame index after cleaning
Generate a final cleaning report
Export the cleaned dataset as a new CSV file
Keeps the original CSV file unchanged
